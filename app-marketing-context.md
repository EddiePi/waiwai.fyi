## Value Proposition
- **Problem:** People recreate the same checklist from scratch every time a recurring event comes up (packing for a trip, weekly chores, home maintenance), and coordinating that list with other people (family, roommates, travel companions) is clunky across most task apps.
- **Target Audience:** Households/families coordinating shared recurring tasks, and travelers who repeat the same packing/trip-prep routine. (Secondary: roommates and solo productivity users.)
- **Unique Differentiator:** Template-first model — build the task list once, then regenerate a clean, ready-to-use checklist every time the event recurs — combined with real-time collaborative checklists and no account/sign-up requirement (anonymous device ID via Firebase).
- **Elevator Pitch:** Wholistic turns anything you do on repeat — packing, chores, routines — into a reusable template you can relaunch, share, and track in a calendar, without rebuilding the list from scratch every time.
